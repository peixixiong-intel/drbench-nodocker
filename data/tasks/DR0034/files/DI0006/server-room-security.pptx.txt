Evolution of Lee's Market Server Room Security Established in 2010, the IT &amp; Security department began with basic password protection In 2015, the team introduced 2-factor authentication for server room access In 2018, CCTV cameras were added to monitor physical access to the server room In 2020, the department implemented a system of unique keycards for each employee In 2022, Lee's Market initiated regular security audits and vulnerability assessments 2024 saw the introduction of a dedicated cybersecurity team within the department
